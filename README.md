# Exploratory Data Analysis (EDA)

## Overview

An R-based exploratory data analysis project examining applicant and recruitment data. The analysis explores distributions, relationships, data quality, outliers, and recruitment trends while preparing data for further analysis and reporting.

## Features

* Frequency distributions and summary statistics
* Histograms, bar charts, boxplots, and scatterplots
* Correlation and relationship analysis
* Outlier and missing-value detection
* Numeric data cleaning and standardization
* Recruitment and applicant trend analysis
* Data quality assessment and preprocessing

## Input

`Job_Applicants.csv`

## Analysis

The project examines categorical and numeric applicant variables including:

* Job titles, position types, certification areas, and recruitment sources
* Applicant locations, experience, GPA, and employment interests
* Candidate counts and salary information
* Relationships between applicant volume and compensation

Data quality checks identify unusual values, parse numeric fields stored as text, and standardize inconsistent values.

## Output

Produces summary statistics, frequency tables, visualizations, and cleaned variables for:

* Recruitment analytics
* ATS reporting
* Workforce planning
* Dashboard development
* Statistical modeling

## Packages
